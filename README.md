# Offline Field Issue Tracker

**Weder Strategies – Full Stack Developer Internship Exercise**

An offline-first, mobile-responsive web application designed for field workers to report infrastructure problems (e.g., broken water points, damaged equipment, safety concerns).

The application allows reports to be created and stored locally when connectivity is unavailable, and automatically synchronizes with a backend server when connectivity is restored. A **coordinator role** is simulated to review and update report statuses.
